# 昨夜圆车杯 #1 积分计算器

「沉沦者的黑流树海」主题赛事的单选手积分计算工具。

## 使用

双击 `昨夜圆车杯积分计算器.html` 即可在浏览器打开，无需联网，手机/电脑均可。

1. 顶部切换 **正式模式 / 娱乐模式**
2. 填写结算分、零件箱得分（或零件箱数量，自动 ×7.5）
3. 正式模式选择难度（自动套用难度加分与关卡分值）
4. 勾选/填写各加分项，总分实时自动计算
5. 点「复制结果」一键复制完整明细

## 规则说明

- 基础通关得分 =（结算分 − 零件箱得分）÷ 2
- 正式模式难度加分：N10=30 → N15=290
- 娱乐模式统一按 N15 规则（难度加分 +290）
- 含扣分项（板藤、非本家超额、交换探测先锋、商店超支等，红色标注）
