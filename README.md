# 昨夜圆车杯 #1 积分计算器

「沉沦者的黑流树海」主题赛事的单选手积分计算工具。

🌐 **在线使用**：https://Christina-tz.github.io/yuanche-cup-score-calculator/

## 使用

手机/电脑浏览器直接打开上面的链接即可，无需下载、无需联网依赖。

1. 顶部切换 **正式模式 / 娱乐模式**
2. 填写结算分、零件箱得分（或零件箱数量，自动 ×7.5）
3. 正式模式选择难度（自动套用难度加分与关卡分值）
4. 勾选/填写各加分项，总分实时自动计算
5. 点「复制结果」一键复制完整明细

> 也可以下载 `index.html` 本地双击打开使用。

## 规则说明

- 基础通关得分 =（结算分 − 零件箱得分）÷ 2
- 正式模式难度加分：N10=30 → N15=290
- 娱乐模式统一按 N15 规则（难度加分 +290）
- 含扣分项（板藤、非本家超额、交换探测先锋、商店超支等，红色标注）
